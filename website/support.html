Support

How can we help?

Adport open source and Adport Cloud

For account access, provider connections, billing, security, or plugin questions, email yannick@adport.dev. Include the affected provider and your Adport organization name, but never send passwords, access tokens, refresh tokens, API keys, or provider application secrets.

Cloud account and provider access

Sign in to Adport Cloud to review provider connection status. If a connection fails, include the visible error message and approximate time in your support request. Sensitive credentials and raw OAuth grants are not needed for troubleshooting.

Billing

Organization owners can review the current plan from the Plan page in Adport Cloud. For invoice, cancellation, or access questions, contact support from the email address associated with the organization.

Security

Report suspected vulnerabilities privately to yannick@adport.dev. Do not include live credentials or user data in an initial report. We will provide a secure follow-up channel if sensitive evidence is required.

Data deletion

Provider disconnection and organization deletion are documented on the User Data Deletion page.

Open-source help

For reproducible bugs or feature requests that contain no private account data, open an issue in the Adport GitHub repository.
