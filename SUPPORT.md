# Getting help

Start with the [documentation index](docs/README.md), [provider connection guide](docs/providers.md), and `adport doctor`. The local CLI requires your own provider application and permissions; hosted Cloud access is available through the [waitlist](https://adport.dev/#waitlist).

Search [existing issues](https://github.com/ynnickw/adport/issues) before opening a [bug report or feature request](https://github.com/ynnickw/adport/issues/new/choose). Include the Adport version, Node.js version, operating system, provider, a minimal reproduction, and sanitized output. Maintainers provide community support as time permits.

For Cloud account help, use [Adport support](https://adport.dev/support). For a vulnerability, follow [SECURITY.md](SECURITY.md) and report it privately. Community conduct concerns go to the contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Never include tokens, API keys, OAuth client secrets, private keys, private account identifiers, or unsanitized request logs in a public report.
