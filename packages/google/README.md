# @adport/provider-google

Google Ads provider for adport (REST interface, no heavy SDK).

This package is part of [Adport](https://github.com/ynnickw/adport), an open-source control plane for paid media. Most users should install the [`adport` CLI](https://www.npmjs.com/package/adport), which assembles the provider modules and shared policy engine.

Requires Node.js 22.13 or newer. Advertising mutations must use the shared preview/apply policy gate. Provider credentials and approvals are configured separately; package installation does not grant platform access.
