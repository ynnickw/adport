# @adport/provider-matomo

Connect a Matomo Cloud or self-hosted site to Adport with a view token. The package reads aggregate acquisition reports and configured goals through `analytics_acquisition_report` and `analytics_goals`. Configure `MATOMO_URL` and `MATOMO_TOKEN_AUTH` or run `adport connect matomo`.

See the [connection guide](https://github.com/ynnickw/adport/blob/main/docs/providers/matomo.md) and [shared reporting contract](https://github.com/ynnickw/adport/blob/main/docs/providers/website-analytics.md).
