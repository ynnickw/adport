# adport

The Adport CLI: manage advertising accounts from the terminal with previewed writes.

```sh
npm install -g adport
adport --demo accounts
adport connect google
adport mcp
```

Requires Node.js 22.13 or newer. Local connections use your own provider applications and credentials. Every advertising mutation passes through the shared preview/apply policy engine.
