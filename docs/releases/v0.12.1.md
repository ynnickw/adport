# v0.12.1

## Changes

- Large Google Ads query results now show a table in query order. Search terms, keywords, campaign names, ad IDs and other returned fields help distinguish rows that share an ad-group name.
- The table shows spend alongside the other metrics returned by the query. Spend uses the reported currency's display precision, and CTR is shown as a percentage. Details retains the original values.
- When a result omits the currency, the widget flags it once. When rows have identical labels, it explains which additional fields can distinguish them. Small, clearly labeled comparisons and identifiable daily trends still use charts.

[Full change set](https://github.com/ynnickw/adport/compare/v0.12.0...v0.12.1)

## Upgrade notes

Update the CLI with `npm install -g adport@0.12.1`. Self-hosted MCP clients that pin `@adport/mcp` can update to `0.12.1`. The hosted connector serves the update automatically for new results. Previously published widget resource addresses remain available for cached conversations.

## Validation

Widget tests cover a 162-row result, repeated ad-group names, missing identifiers, mixed currencies and precise source values. A 162-row sample rendered at desktop and phone widths with all rows accessible. Provider contract tests use fixture responses.
