# v0.12.2

## Changes

- Comparable records now appear in a table with one set of column headings. Google Ads country lookups show the country name, country code, and target ID. Joined queries qualify columns such as campaign name and ad group name so they stay distinguishable.
- Lists with 15 or more displayed rows can be filtered by name, code, ID, or another visible value. Filtering happens in the widget. The Details section keeps the full response in its original order.
- The shared layout also supports language lookups and catalog records. Records with more complex shapes use their nested names as card headings. Compact tables keep their columns side by side on phones.

[Full change set](https://github.com/ynnickw/adport/compare/v0.12.1...v0.12.2)

## Upgrade notes

The hosted connector loads the update automatically on new results. Self-hosted clients can update to `@adport/mcp@0.12.2`. To update the CLI, run `npm install -g adport@0.12.2`. Older widget resource addresses remain available for cached conversations.

## Validation

The preview was tested with a read-only Google Ads lookup of 17 countries. Filtering by `2246` returned Finland on desktop and phone layouts. Additional fixtures cover shared field names, repeated IDs, missing values, and mixed record shapes. Local validation passed all 434 MCP tests. The Cloud suite passed 842 tests and skipped 157 environment-dependent integration tests.
