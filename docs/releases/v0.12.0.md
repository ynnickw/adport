# v0.12.0

## Changes

- Tool Availability shows matching tools and explains which connections or permissions are needed to use them.
- Measurement Health surfaces event and pixel diagnostics from connected providers that expose them. Catalog processing shows item-level status, and media distribution shows the planned changes before confirmation.
- New views show Apple change history, Google Ads experiment comparisons, keyword ideas and forecasts from Google Ads and Microsoft Advertising where supported, and Apple Ads recommendations.
- Reports from GA4, Search Console, and supported ad providers can page through large results. Record lists preserve the original account, dates, and filters as you page.
- Tables and action receipts are easier to read in narrow MCP hosts.

[Full change set](https://github.com/ynnickw/adport/compare/v0.11.1...v0.12.0)

## Upgrade notes

Update with `npm install -g adport@0.12.0`. Clients that pin `@adport/mcp` can update to `0.12.0`. Existing widget resource URIs remain available. Available views and diagnostics depend on the connected provider and account permissions. Media distribution uses the existing preview and confirmation flow.

## Validation

Local validation covered the workspace build, tests, type checking, and widget rendering at narrow and wide widths. Provider contract tests used mocked responses. Live-provider integration tests that require credentials were skipped.
