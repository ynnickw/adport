# v0.7.0

## Campaign setup and provider tools

- Apple Ads adds explicit tools to read ad groups, keywords, negative keywords, ads, creatives, and product pages; create keyword batches, exclusions, creatives, and paused ads; and edit campaign schedules. Account discovery now includes currency and timezone metadata. Negative keywords remain enabled so exclusions take effect, and bulk-create failures report that callers must read back results before retrying. [#89](https://github.com/ynnickw/adport/pull/89)
- Google campaign creation supports Manual CPC, Maximize Clicks, Maximize Conversions, and Maximize Conversion Value, plus location and language targeting. Search campaigns default to Google Search with search partners and Display expansion disabled; location targeting defaults to presence only. [#88](https://github.com/ynnickw/adport/pull/88)
- Meta adds account-checked campaign list/detail tools, optional selected-Page scoping, explicit ad-set bidding controls, and advertiser/payer fields for EU targeting. Bid and cost caps require a bid amount; minimum ROAS requires a ROAS constraint and value optimization. [#78](https://github.com/ynnickw/adport/pull/78), [#87](https://github.com/ynnickw/adport/pull/87), [#91](https://github.com/ynnickw/adport/pull/91), [#92](https://github.com/ynnickw/adport/pull/92)

## Approval safety and MCP

- Pending write approvals are bound to both the operation and the effective safety policy. Changing limits, protected accounts, or paused-creation settings requires a fresh preview. The preview/apply gate can no longer be disabled in policy configuration. [#109](https://github.com/ynnickw/adport/pull/109)
- Embedded write previews use hold-to-apply, support the native ChatGPT tool bridge, and prevent a second submission after an unconfirmed result. Read back the resource before retrying an uncertain write. [#88](https://github.com/ynnickw/adport/pull/88)
- MCP tools expose display titles and corrected account-scoped annotations. Hosted production catalogs expose explicit operations; generic provider dispatchers and `recommendation_apply` remain available through the local CLI/stdio registry. [#77](https://github.com/ynnickw/adport/pull/77), [#87](https://github.com/ynnickw/adport/pull/87), [#90](https://github.com/ynnickw/adport/pull/90)
- Dismissing an unknown recommendation returns a clear input error. Package documentation, packing checks, and the release workflow now validate isolated CLI installation before publication. [#93](https://github.com/ynnickw/adport/pull/93), [#121](https://github.com/ynnickw/adport/pull/121)

## Cloud and website changes since v0.6.1

The repository also includes organization and project isolation, team access controls, billing lifecycle fixes, account-selection and onboarding improvements, updated assistant setup, public support, and refreshed website resources and branding. Cloud and website deployments have separate lifecycles; installing this package release does not deploy Cloud or change provider/connector approval status.

## Upgrade notes

- Upgrade the CLI with `npm install -g adport@0.7.0`. All 14 public packages use version `0.7.0`; Node.js 22.13 or later remains required. Restart local MCP clients after upgrading.
- Create fresh previews after upgrading. Pending tokens created with older versions do not include the policy binding and will be rejected. Policy files with `require_validation: false` must be changed to `true` or omit that field.
- Review Google Search network defaults before creating new campaigns. Set `search_partners` or `display_expansion` explicitly when needed. Existing campaigns are not changed by upgrading.
- Budgets keep their existing provider units: Google uses micros and Meta uses minor currency units. Meta `bid_amount` also uses minor currency units; `roas_average_floor` is scaled by 10,000.
- Provider permissions, app reviews, and account eligibility still apply. Contract tests do not establish live provider acceptance. The default policy continues to force paused creation for serving resources; enabled Apple negative keywords restrict delivery.
