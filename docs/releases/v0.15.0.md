# v0.15.0

## Changes

- List campaigns and change campaign status across 13 advertising providers with `campaigns_list` and `campaign_set_status`. Both tools take a `provider` and an `account_id`. Campaign status changes use Adport’s preview and approval flow.
- Review a before-and-after estimate in Cloud’s Tool access dialog. On a Full connection, **Use Standard** prepares a switch and suggests connected platforms when the connection includes all platforms. Save to apply the change. Full also links to the OpenAI Responses and Claude Messages examples for on-demand tool loading.
- Authorize an assistant for accessible projects in multiple organizations. Cloud also improves workspace naming, profile settings, project transfers, and invitations. [Workspace settings and assistant authorization, #214](https://github.com/ynnickw/adport/pull/214)

## Upgrade notes

- **Breaking change for hosted Standard connections.** Update saved campaign listing and status calls to the shared names and provide the target platform. `capabilities_list` shows which tools the connection exposes. Refresh tools in the client after a profile change. Full and the CLI continue to expose native tool names. Google GAQL and LinkedIn’s native activation tool remain available in Standard.
- Install `adport@0.15.0` for the CLI or restart a self-hosted MCP server with `@adport/mcp@0.15.0`. Self-hosted Cloud operators upgrading from v0.14.0 should apply the migrations from #214 before deploying.

## Validation

The hosted discovery fixture exposes 224 Standard tools with all platforms enabled, down from 246. Campaign contract tests use fixtures to verify account scoping, provider-specific status mappings, and the preview and approval flow. The default CI checks include the hosted MCP catalog and clean package installation. Cloud database and HTTP integration tests require an opt-in environment.
