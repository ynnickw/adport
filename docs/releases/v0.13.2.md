# v0.13.2

## Changes

- Meta List Ads and Apple Report now display their data when an assistant forwards the tool response as nested JSON. If a response arrives incomplete, the widget explains why it cannot display the result.
- Meta ad cards show effective delivery status. An ad with an active configuration and a paused ad set displays “Ad set paused.”
- Apple reports show spend, taps and installs for a single returned row when Apple omits the report total. The row label identifies the campaign, keyword or search term when available. Spend charts keep their layout when the window is resized.
- The website also adds paid search and Apple Ads calculators and reporting guides for Bing and Reddit. [#208](https://github.com/ynnickw/adport/pull/208)

## Upgrade notes

Run the tool again to see the updated widget on the hosted connector. For self-hosted installations, update to `@adport/mcp@0.13.2` and restart the MCP server. CLI users can run `npm install -g adport@0.13.2`.

## Validation

Browser checks used synthetic Meta ads and Apple report rows at desktop and mobile widths. Tests covered both host delivery methods, effective ad status, row-level metrics and error handling. The local workspace suite passed 5,294 tests and skipped 158 opt-in Cloud tests.
