# v0.13.0

## Changes

- Create and edit shared Google Ads negative keyword lists, see which campaigns use them, and attach or detach them in bulk. You can also add exclusions directly to multiple campaigns. The preview reports existing and duplicate keywords. [#197](https://github.com/ynnickw/adport/pull/197)
- Set desktop and mobile landing pages, tracking templates, and final URL suffixes when adding keywords. Update or clear those fields on up to 1,000 existing keywords across ad groups. Omitted fields keep their saved values. [#198](https://github.com/ynnickw/adport/pull/198)
- Inspect and create custom conversion goals, see which actions a campaign bids on, and switch up to 50 campaigns between custom goals, standard goals, and account defaults. The widget shows the requested campaigns’ bidding settings alongside the paginated goal list. [#199](https://github.com/ynnickw/adport/pull/199)
- Adport Cloud also has simpler account and assistant setup, mobile onboarding, and paginated audit history. [#200](https://github.com/ynnickw/adport/pull/200)

Thanks to Laurent Davesne for contributing the three Google Ads features.

## Upgrade notes

Install with `npm install -g adport@0.13.0`. Self-hosted MCP clients can update `@adport/mcp` to `0.13.0` and restart their server. Negative keyword and keyword URL tools are in the standard and full profiles. Custom conversion goals use the full profile alongside other specialist measurement tools. Each write uses Adport’s existing preview and approval flow.

Google requires a keyword-level final URL when mobile or tracking overrides are set. To restore the ad’s landing page, clear the keyword’s URL overrides. For campaign goal changes, read the current goal configuration first. Adport checks that snapshot before applying the change. [Google Ads provider guide](../providers.md) · [Campaign conversion goals](../providers/google-conversion-goals.md)

## Validation

All three features were exercised against the real Google Ads API using a paused Search campaign. The checks covered saving and reading back exclusions, keyword URLs, and campaign goal settings, followed by cleanup. The temporary campaign recorded zero impressions and zero spend. Repository checks cover the shared CLI and MCP tool registry, provider request formats, approval flow, and widget pagination.
