# v0.6.0 — five more ad providers

- Add Snapchat, Spotify, Pinterest, LinkedIn and X Ads packages, bringing the
  local CLI/MCP and cloud runtime to 11 supported provider modules.
- Add local BYO connection commands with account-discovery verification and
  permission-restricted credential storage.
- Add hosted OAuth adapters, provider cards and organization-specific test
  rollout controls. X uses OAuth 1.0a; the other four use OAuth 2.0.
- Preserve shared preview/approval policy enforcement, paused creation,
  account-scoped tools, plan limits and tenant isolation.
- Protect refresh-token rotation against replaced or disconnected grants.
- Document provider-specific metrics, pagination, date ranges, partial native
  coverage and approval requirements.
- Skip private workspaces during npm publication and check the public tree
  before release.

All 45 build/test/typecheck tasks passed locally: 566 tests passed and 18
opt-in database/HTTP tests were skipped. Contract fixtures are not proof of
live provider acceptance. No campaign mutation was performed for this release.

Cloud rollout remains controlled: LinkedIn still requires its application
approval, and an approved app does not by itself verify every account/report
or write operation. See each provider guide for the implemented surface.
