# v0.10.0

## OpenAI Ads

- Connect an OpenAI Ads advertiser account from Adport Cloud or with `adport connect openai`. The CLI, local MCP server and Cloud runtime share the new provider. Read campaigns, ad groups, ads, reports and conversion diagnostics. ([#173](https://github.com/ynnickw/adport/pull/173))
- Create paused campaigns, change an existing budget, and pause or activate campaigns, ad groups and ads through the existing preview and approval flow. Campaigns use exactly one daily or lifetime budget; budget edits retain that budget type. Objective/billing pairs and normalized country-targeting receipts are checked explicitly. ([#175](https://github.com/ynnickw/adport/pull/175))

## Cloud and provider improvements

- Google Tag Manager and Search Console connections are available to all Cloud projects, subject to Google consent and account permissions. Google Analytics availability remains restricted while verification is pending. ([#165](https://github.com/ynnickw/adport/pull/165), [#166](https://github.com/ynnickw/adport/pull/166))
- Microsoft conversion-goal tools support enhanced conversions. Reddit connections can request conversion-event access explicitly, and reconnect links preserve the selected grant. Existing account terms and provider permissions still apply. ([#173](https://github.com/ynnickw/adport/pull/173))
- Creative-library widgets retain the loaded page when a host echoes a media result. Existing widget resource aliases remain available. ([#160](https://github.com/ynnickw/adport/pull/160))

## Discovery and validation fixes

- Compact hosted MCP discovery and on-demand tool search reduce publisher payloads. Tool descriptions, visibility, campaign titles and Spotify update annotations preserve the reviewed behavior and describe replacement operations accurately. ([#161](https://github.com/ynnickw/adport/pull/161), [#162](https://github.com/ynnickw/adport/pull/162), [#163](https://github.com/ynnickw/adport/pull/163), [#176](https://github.com/ynnickw/adport/pull/176), [#177](https://github.com/ynnickw/adport/pull/177))
- X preroll destination URLs reject raw control characters before URL normalization. Runtime and build dependencies are refreshed, including Commander 15.1. ([#174](https://github.com/ynnickw/adport/pull/174))

## Upgrade notes

- Install the CLI with `npm install -g adport@0.10.0`. All public packages share version `0.10.0` and require Node.js 22.13 or later. Restart local MCP clients after upgrading to refresh tool and widget discovery.
- Cloud self-hosters must apply `supabase/migrations/20261118035103_openai_ads_connections.sql` before starting the new Cloud build. A package release does not deploy Cloud or publish a connector/plugin listing.
- OpenAI Ads requires an Advertiser API key and account eligibility; partner keys and Ads OAuth are not supported. Creation previews are local, and account-currency budget minimums are enforced by the native API. This release does not add OpenAI ad-group, ad, upload or tracking-source creation tools.

## Validation

Release validation covers repository checks, workspace builds and typechecks, provider contract tests, and isolated package installation. The release workflow also verifies the public npm CLI and matching workspace dependencies before publishing the GitHub release.

Provider contract tests use mocked API responses. Selected OpenAI and Microsoft workflows were separately checked against real accounts using paused QA resources; their coverage and remaining limits are recorded in the provider guides. Populated OpenAI delivery/conversion metrics and activation remain untested. Credential-dependent database integration checks are separate from the normal test suite.
