# v0.13.1

## Changes

- Meta Insights reports now show which campaigns, ads, or placements spent the most, alongside the outcomes returned by Meta. Multi-metric reports use a table. A shared reporting period appears once, and spend uses the reported account currency when available.
- Small, labeled comparisons can still use bars. If a report has several rows with no distinguishing labels, the widget explains which field would identify them. Details keeps the original values, precision, and row order.
- Default Meta Insights queries request the ID and name at the selected reporting level, plus account currency. Custom queries keep the fields you select and return the requested breakdown names with the rows.
- Adport Cloud also includes the dashboard navigation, mobile onboarding, and assistant access improvements shipped since v0.13.0. [#206](https://github.com/ynnickw/adport/pull/206)

## Upgrade notes

The hosted connector uses the new widget for fresh results. Self-hosted users can update to `@adport/mcp@0.13.1` and restart the MCP server. For the CLI, run `npm install -g adport@0.13.1`.

## Validation

Desktop and phone previews used a synthetic 17-placement report. Regression tests cover mixed currencies, missing labels, and ranking before the 1,000-row display limit. The local workspace suite passed 5,285 tests and skipped 158 opt-in Cloud tests.
